# Lumina Jewels (ルミナ・ジュエルズ)

視覚と聴覚で楽しむ、プレミアム感と静寂をテーマにしたリラクゼーションパズルWebゲームです。

## 特徴
- **視覚的癒やし**: ディープカラーを基調とした背景と、ゴールドの光輝くパーティクル演出。
- **聴覚的癒やし**: Web Audio APIを用いたクリアな宝石音と、倍音豊かなクリア和音演出。
- **100ステージ構成**: 難易度が徐々に上がっていくライツアウトベースの論理パズル。
- **完全単一ファイル構造**: 外部ライブラリ非依存で軽量かつ高速動作。

## プレイ方法（GitHub Pagesで公開する場合）
1. 本リポジトリをGitHubにプッシュします。
2. リポジトリの **Settings** > **Pages** を開きます。
3. **Source** を `Deploy from a branch` に設定し、`main` (または `master`) ブランチを選択して保存します。
4. 発行されたURLにアクセスすることで、PCやスマートフォンのブラウザでそのままプレイできます。
